# 01 项目交付与验收工作区

本目录用于保存交付包、上线检查、验收材料、培训资料、运维交接、遗留问题和交付总结。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_inputs/`：发布版本、部署记录、测试报告、合同、验收标准和已知问题。
- `02_packages/`：源代码、构建产物、部署包、交付清单和版本说明。
- `03_acceptance/`：验收计划、验收记录、签收材料和补充说明。
- `04_training/`：用户手册、操作说明、培训材料、FAQ 和培训记录。
- `05_operations/`：运维交接清单、账号权限、应急预案、联系人和观察期记录。
- `06_issues/`：遗留问题、责任人、期限、关闭状态和书面接受结论。
- `07_summary/`：交付总结、项目复盘和下一轮迭代建议。

## 使用建议

- 交付材料应能关联到需求、合同、变更、发布版本或测试结论。
- 影响验收的问题必须明确关闭状态或书面接受结论。
- 运维资料、账号权限和应急联系人应在交付前完成确认。
