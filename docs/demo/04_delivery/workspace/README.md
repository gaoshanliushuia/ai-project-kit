# workspace 目录说明（交付组）

`workspace` 是交付组的执行区，用于保存交付包、验收记录、用户资料、培训资料、运维交接和遗留问题闭环。

## 本组目录

```text
workspace/
└── 01_delivery/
```

## 总体原则

- 交付资产应以客户或业务使用方可接收、可验证、可签收为标准。
- 交付材料应能追溯到需求、合同、变更、发布版本或测试结论。
- 默认只创建到 `01_delivery/` 这一层；更细的子目录按本级 README 建议按需创建。
- AI 使用记录在 `05_gov/workspace/` 登记，并标注来源组 `04_delivery`。

## 推荐工作方式

1. 接收 `02_build/workspace/05_release/` 的发布基线。
2. 汇总源代码、构建产物、部署资料、用户手册、培训材料和运维资料。
3. 根据合同、需求和测试结论组织验收。
4. 记录签收结论、遗留问题和后续支持安排。
