# 代码实现与工程管理 Skill

## 目标

把设计项转化为可构建、可测试、可审查、可发布的代码实现。

## 适用角色

- `Developer Agent`

## 输入

需求编号、设计项、接口契约、数据模型、代码规范、分支策略、测试要求。

## 输出

开发任务、实现计划、测试记录、构建记录、代码评审问题、缺陷修复记录。

## 执行步骤

- 把设计项拆成可追踪的开发任务。
- 确认影响范围、依赖、配置项和验证方式。
- 实现代码并补齐关键路径测试或人工验证证据。
- 记录代码评审问题、修复结论和遗留风险。
- 整理交给测试和发布的变更说明。

## 使用要求

- 先读取本阶段 `rules/RULE.md`，再生成或检查阶段产物。
- 所有结论必须能追踪到输入材料、编号、负责人或评审记录。
- AI 生成内容只作为初稿或检查建议，关键结论必须由阶段负责人确认。
- 发现可复用经验时，回写本阶段 `rules/`、`skills/` 或 `prompts/`，并在后续版本发布中说明。
