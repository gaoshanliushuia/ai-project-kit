## 5. 回滚说明

Demo 级回滚策略：

- 备份数据库。
- 保留上一版本后端服务包。
- 发布失败时回退后端服务包。
- 数据库脚本如已执行，按回滚说明或备份恢复。

## 6. 交接给交付阶段

交付阶段接收：

- 最终版本号。
- 发布清单。
- 部署说明。
- 发布验证结论。
- 已知问题和风险接受记录。

AI-Agent 可辅助生成发布说明和交付清单初稿，发布执行和风险接受必须由人工确认。

## 10. 发布验证清单

| 验证项 | 验证方式 | 通过标准 |
|--------|----------|----------|
| 登录 | 使用 `academic_admin` 登录 | 进入主页 |
| 菜单权限 | 切换班主任、任课教师账号 | 菜单按角色变化 |
| 学生管理 | 查询、新增、重复学号 | 正向保存，重复失败 |
| 学生课程 | 重复分配课程 | 返回业务错误 |
| 成绩管理 | 录入 0、100、101 | 0 和 100 成功，101 失败 |
| 越权访问 | 班主任查询其他班数据 | 接口拒绝或数据过滤 |

## 11. 回滚触发条件

满足任一条件时必须停止发布或回滚：

- 后端服务无法启动。
- 数据库初始化脚本执行失败且无法补偿。
- 登录不可用。
- 权限过滤失败。
- 成绩录入规则失效。
- 发布验证中出现阻塞缺陷。

## 12. 回滚步骤

| 步骤 | 操作 |
|------|------|
| 1 | 停止新版本前端和后端服务 |
| 2 | 恢复上一版本服务包或停止 Demo 发布 |
| 3 | 如数据库脚本已执行，使用备份恢复或执行回滚脚本 |
| 4 | 记录回滚原因、影响范围和责任人 |
| 5 | 将问题回传到 `03_qa/workspace/02_changes/` |
