# 02 详细设计工作区

本目录用于保存详细设计阶段的模块设计、接口设计、流程设计、状态设计和评审记录。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_inputs/`：需求编号、架构决策、接口约束、数据规则和安全要求。
- `02_modules/`：模块职责、边界、依赖关系、任务拆分和设计项清单。
- `03_interfaces/`：接口契约、字段定义、错误码、鉴权、幂等和超时规则。
- `04_flows/`：主流程、分支流程、异常流程、补偿流程和时序图。
- `05_states/`：状态机、状态流转条件、禁止流转规则和状态影响分析。
- `06_reviews/`：设计评审记录、问题清单、关闭证明和设计基线。

## 使用建议

- 设计项应能关联到需求编号和架构决策编号。
- 核心接口和状态规则应写到可测试、可实现的粒度。
- 交接给开发和测试时，应包含边界条件、异常策略和测试关注点。
