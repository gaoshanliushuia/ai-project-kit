## 4. AI-Agent 与人工分工

| 工作 | 执行主体 |
|------|----------|
| 根据需求和功能说明生成测试用例初稿 | AI-Agent |
| 补充边界值、权限和异常场景 | AI-Agent 初稿，人工确认 |
| 准备测试环境和测试数据 | 人工 |
| 执行测试并记录实际结果 | 人工 |
| 汇总缺陷趋势和质量报告初稿 | AI-Agent |
| 判断是否建议发布 | 人工 |

## 5. 出口标准

- 高优先级需求 REQ-001、REQ-003、REQ-004、REQ-005、REQ-007 必须有用例覆盖。
- 阻塞缺陷必须关闭或获得风险接受。
- 权限类问题不得以“已知问题”形式放行。
- 质量报告必须明确是否建议发布。

## 7. 详细用例样例

| QA 编号 | 前置条件 | 操作步骤 | 测试数据 | 预期结果 |
|---------|----------|----------|----------|----------|
| QA-004 | 已存在学生 `S2026001` | 教务管理员新增学号 `S2026001` 的学生 | 学号：`S2026001` | 保存失败，错误码 `DUPLICATE_DATA` |
| QA-005 | `head_teacher_01` 绑定七年级一班 | 班主任登录后查询学生列表 | 七年级一班、七年级二班均有学生 | 只返回七年级一班学生 |
| QA-007 | 学生 `S2026001` 已绑定 `2026-S1 + 语文` | 再次新增相同课程关系 | term=`2026-S1`, course=`语文` | 保存失败，提示课程关系重复 |
| QA-009 | 学生存在有效课程关系 | 分别录入 `-1` 和 `101` | score=-1, score=101 | 保存失败，错误码 `VALIDATION_ERROR` |
| QA-010 | `teacher_zhang` 只任教语文 | 尝试录入数学成绩 | course=`数学` | 操作被拒绝，错误码 `FORBIDDEN` |

## 8. 缺陷登记模板

| 字段 | 填写要求 |
|------|----------|
| DEF 编号 | 例如 DEF-001 |
| 来源用例 | 必须关联 QA 编号 |
| 关联需求 | 必须关联 REQ 编号 |
| 关联设计 | 必须关联 DES 编号 |
| 严重级别 | 阻塞 / 严重 / 一般 / 轻微 |
| 复现步骤 | 写清账号、页面、输入数据和操作 |
| 实际结果 | 系统实际表现 |
| 期望结果 | 需求或设计中的期望 |
| 影响范围 | 影响模块、角色、数据或发布 |
| 回传对象 | CODE 或 DES 编号 |

## 9. 回归测试要求

- DEF-001 修复后必须重跑 QA-008、QA-009。
- DEF-002 修复后必须重跑 QA-005，并补充教务管理员查询全量学生的正向用例。
- 权限类缺陷修复后，必须同时验证前端菜单和后端接口。
- 回归通过后才能把质量报告结论改为建议发布。
