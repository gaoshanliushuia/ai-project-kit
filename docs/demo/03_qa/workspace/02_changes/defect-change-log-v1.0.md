## 7. 变更影响分析模板

| 字段 | 填写要求 |
|------|----------|
| CR 编号 | 例如 CR-003 |
| 变更来源 | 缺陷、客户反馈、法规要求、内部优化 |
| 变更描述 | 说明变化前和变化后 |
| 影响需求 | 列出 REQ 编号 |
| 影响设计 | 列出 DES 编号 |
| 影响数据库 | 列出 DB 编号或说明无影响 |
| 影响代码 | 列出 CODE 编号 |
| 影响测试 | 列出 QA 编号和需新增用例 |
| 审批结论 | 接受、拒绝、延期、合并处理 |
| 关闭证据 | 代码、测试、文档和发布记录 |

## 8. 配置基线要求

本 Demo 的配置基线包括：

- 需求基线：`BASE-REQ-20260612-001`
- 发布版本：`v1.0.0-demo`
- 数据库脚本版本：`DB-v1.0.0-demo`
- 前端和后端构建版本：与发布版本一致

任何影响基线的修改必须记录 CR 编号。不得直接覆盖已签发文档或发布材料。
