# 02 变更与配置管理工作区

本目录用于保存变更申请、影响分析、审批记录、实施跟踪、回传实施组事项和变更关闭材料。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_requests/`：变更申请、缺陷修复请求、客户反馈和监管要求。
- `02_impact-analysis/`：范围、成本、周期、质量、数据、接口和测试影响分析。
- `03_approvals/`：变更评审、审批结论、风险接受和延期记录。
- `04_execution/`：变更实施计划、执行记录、受影响项同步和验证结论。
- `05_feedback-to-build/`：需要实施组处理的结构化回传事项。
- `06_closure/`：变更关闭记录、追踪链路复核和复盘材料。

## 使用建议

- 每个变更必须有唯一 CR 编号、状态、提出人和处理结论。
- 受影响需求、设计、代码、测试和发布项应明确记录。
- 回传实施组的内容应引用 REQ/DES/DEF/CR，并说明期望处理结果。
