# 需求基线 v1.0

项目：中学教务管理系统 Demo

基线编号：BASE-REQ-20260612-001

状态：已签发

## 1. 基线范围

本基线覆盖中学教务管理系统 Demo 的一期范围：

- 登录。
- 主页。
- 学生管理。
- 班级管理。
- 教师管理。
- 学生课程管理。
- 学生成绩管理。

## 2. 正式需求清单

| 编号 | 模块 | 需求说明 |
|------|------|----------|
| REQ-001 | 登录 | 用户可使用账号密码登录系统 |
| REQ-002 | 主页 | 首页展示当前用户信息和常用功能入口 |
| REQ-003 | 学生管理 | 教务管理员可维护学生基础信息 |
| REQ-004 | 班级管理 | 教务管理员可维护年级、班级和班主任 |
| REQ-005 | 教师管理 | 教务管理员可维护教师基础信息和任课关系 |
| REQ-006 | 学生课程管理 | 教务管理员可维护学生课程关系 |
| REQ-007 | 学生成绩管理 | 任课教师可录入并查询学生成绩 |
