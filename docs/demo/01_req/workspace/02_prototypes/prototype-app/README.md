# 中学教务管理系统 Vue 原型

本目录保存需求阶段产出的可运行前端原型，用于业务确认页面、流程、字段、角色菜单和交互效果。它不是正式生产代码，而是需求阶段的可视化交付物。

## 1. 原型目标

- 帮助业务人员直观看到登录、主页和各业务模块的页面效果。
- 支持业务分析人员根据反馈快速调整页面字段、菜单和交互。
- 为详细设计阶段的软件功能说明文档提供视觉和交互依据。
- 为后续开发人员提供布局、字段和操作入口参考。

## 3. 运行方式

进入本目录：

```bash
cd docs/demo/01_req/workspace/02_prototypes/prototype-app
npm start
```

默认访问：

```text
http://localhost:4173
```

如需更换端口：

```bash
PORT=4300 npm start
```

Windows PowerShell：

```powershell
$env:PORT=4300; npm start
```

## 4. 技术说明

- 使用 Node.js 启动本地静态服务。
- 页面使用 Vue 3 渲染。
- 当前 Demo 为轻量原型，Vue 从 CDN 加载，避免为需求原型引入复杂构建流程。
- 如公司网络无法访问 CDN，可在后续迭代中改为 Vite + 本地依赖方式。

## 5. AI-Agent 与人工分工

| 工作 | 执行主体 |
|------|----------|
| 根据需求清单生成页面清单和字段初稿 | AI-Agent |
| 生成 Vue 原型页面、模拟数据和角色菜单 | AI-Agent |
| 确认页面是否符合业务操作习惯 | 人工 |
| 确认字段、按钮、权限和页面流转 | 人工 |
| 根据业务反馈迭代原型 | 业务分析人员主导，AI-Agent 辅助 |

## 6. 反馈记录建议

业务确认时建议记录：

| 字段 | 说明 |
|------|------|
| 页面 | 例如学生管理、成绩管理 |
| 反馈人 | 提出反馈的业务人员 |
| 反馈内容 | 需要调整的字段、按钮、流程或展示 |
| 处理结论 | 采纳、暂不采纳、进入后续迭代 |
| 影响产物 | 需求基线、原型说明、软件功能说明或测试用例 |

## 7. 下游交接

交给详细设计阶段：

- 页面清单和页面入口。
- 表格字段、查询字段、表单字段。
- 操作按钮和角色可见性。
- 业务确认后的交互反馈。

交给开发阶段：

- 视觉布局参考。
- 菜单结构参考。
- 表格和表单结构参考。
- 角色切换和权限展示参考。

注意：正式开发不能直接复制原型代码作为生产代码，必须以详细设计阶段输出的软件功能说明文档、接口契约、数据库设计和编码规范为准。
