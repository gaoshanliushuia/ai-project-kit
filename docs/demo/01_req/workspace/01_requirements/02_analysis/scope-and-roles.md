# 范围边界与角色分析

项目：中学教务管理系统 Demo

阶段：需求分析过程产物

## 1. 范围内功能

| 编号 | 模块 | 范围说明 |
|------|------|----------|
| SCOPE-001 | 登录 | 账号密码登录、退出登录、登录失败提示 |
| SCOPE-002 | 主页 | 展示当前用户信息、角色菜单和常用入口 |
| SCOPE-003 | 学生管理 | 学生新增、编辑、查询、停用、班级归属维护 |
| SCOPE-004 | 班级管理 | 年级、班级、班主任和班级状态维护 |
| SCOPE-005 | 教师管理 | 教师基础信息、账号关联和任课关系维护 |
| SCOPE-006 | 学生课程管理 | 学生与课程关系维护，防止重复分配 |
| SCOPE-007 | 学生成绩管理 | 成绩录入、成绩查询、成绩边界校验 |

## 2. 范围外功能

| 编号 | 功能 | 不纳入原因 |
|------|------|------------|
| OUT-001 | 排课算法 | 复杂度较高，不适合作为 Demo 初期范围 |
| OUT-002 | 在线选课 | 涉及学生端和选课规则，暂不纳入 |
| OUT-003 | 家长端 | 涉及外部用户、通知和隐私规则，暂不纳入 |
| OUT-004 | 复杂统计分析 | 后续可作为报表迭代需求 |
| OUT-005 | 第三方系统集成 | Demo 重点展示阶段衔接，不做外部集成 |

## 3. 角色权限初稿

| 角色 | 可访问模块 | 权限说明 |
|------|------------|----------|
| 系统管理员 | 登录、主页、账号角色配置 | 维护系统账号和角色 |
| 教务管理员 | 全部教务模块 | 维护学生、班级、教师、课程、成绩数据 |
| 班主任 | 主页、学生管理、学生成绩管理 | 只能查看本班学生和成绩 |
| 任课教师 | 主页、学生课程管理、学生成绩管理 | 只能查看任教课程学生，录入对应课程成绩 |

## 4. 关键业务规则

- 学生必须归属一个有效班级。
- 教师可以绑定一个或多个课程。
- 同一学生不能重复绑定同一课程。
- 成绩范围为 0-100。
- 班主任只能查看本班学生数据。
- 任课教师只能录入自己任教课程的成绩。

## 5. 下游使用方式

- 架构阶段引用角色和权限边界设计 RBAC 模型。
- 详细设计阶段引用业务规则编写软件功能说明文档。
- 数据库阶段引用实体关系设计学生、教师、班级、课程和成绩表。
- 测试阶段引用范围内外说明设计验收和回归范围。
