# 01 需求收集与需求分析工作区

本目录用于保存需求阶段的项目过程稿、评审稿、基线稿和交接材料。模板默认只创建到本目录；下级目录请按项目规模和管理要求按需创建。

## 建议子目录

- `01_inputs/`：访谈纪要、业务资料、现状流程、合同范围、外部约束。
- `02_analysis/`：范围边界、干系人、业务流程、需求拆分、待确认问题。
- `03_prototypes/`：原型、页面流转、交互说明和原型评审记录。
- `04_requirements/`：需求规格、用户故事、非功能需求、接口和数据需求。
- `05_traceability/`：需求编号、验收条件、来源、优先级和追踪矩阵。
- `06_reviews/`：需求评审记录、问题清单、关闭证明和确认结论。
- `07_baseline/`：已签发需求基线和交接给实施组的材料。

## 使用建议

- 正式需求项应包含唯一 REQ 编号、来源、负责人、优先级和验收条件。
- 过程稿和已签发基线应分开存放，避免实施组引用未确认内容。
- 向实施组交接时，应明确基线版本、变更范围和未关闭事项。
