# 01 AI Governance 工作区

本目录用于保存项目级 AI 使用治理与质量证据，包括使用记录、Prompt 审查、安全检查、代码审查、输出验收、Metrics 和复盘。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_usage-log/`：按组和阶段记录 AI 使用场景、输入输出摘要、负责人和确认结论。
- `02_prompt-reviews/`：Prompt 审查记录、风险项、改写建议和复审结论。
- `03_security-checks/`：数据安全、脱敏确认、敏感信息处理和合规检查记录。
- `04_code-reviews/`：AI 辅助代码审查记录、问题清单、修复和复审结论。
- `05_output-acceptance/`：AI 输出人工验收、采用结论、修改记录和拒绝原因。
- `06_metrics/`：跨组 AI 参与度、Review 次数、验收次数和研发活动指标。
- `07_retrospective/`：经验复盘、最佳实践、风险案例和后续改进项。

## 使用建议

- 治理责任必须由人承担，AI 只能辅助生成检查清单和初稿。
- 涉及敏感数据的 AI 使用必须先完成安全检查或脱敏确认。
- 每条治理记录应能关联到来源组、业务编号和人工确认结论。
