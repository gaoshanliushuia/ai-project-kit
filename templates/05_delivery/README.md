# 05_delivery（交付组）

交付组负责把已发布版本和项目资产交付给客户或业务使用方，并完成验收、资料移交、培训、运维交接和遗留问题闭环。

交付不只是“上线动作”，还包括用户验收时需要接收和签收的资产，例如源代码、构建产物、部署包、用户手册、操作说明、培训材料、验收记录、运维资料和交付总结。

## 本组阶段

| 编号 | 目录 | 职责 |
|------|------|------|
| 01 | `01_delivery` | 项目交付与验收 |

AI 治理统一在 `06_gov/` 维护。

## 协作

- **上游**：接收 `02_build/workspace/05_release/` 的版本、部署、验证和已知问题材料。
- **质量依据**：引用 `03_qa/workspace/` 中的测试报告、缺陷结论和变更闭环记录。
- **验收输出**：形成客户或业务使用方可签收的交付包、验收记录和运维交接资料。
- **治理**：AI 活动在 `06_gov/workspace/` 登记。
