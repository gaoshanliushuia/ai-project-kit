# 03_qa（测试变更组）

测试变更组负责测试、变更管理，并将结构化结论回传实施组。

> 目录名 `qa` 涵盖 **测试 + 变更** 两类工作，详见组内 playbook。

## 本组阶段

| 编号 | 目录 | 职责 |
|------|------|------|
| 01 | `01_testing` | 测试与质量保证 |
| 02 | `02_changes` | 变更与配置管理 |

AI 治理统一在 `05_gov/` 维护。

## 目录结构

```text
03_qa/
├── playbook/    01_testing, 02_changes
└── workspace/
    ├── 01_testing/
    └── 02_changes/
```

## 协作

- **引用上游**：需求基线、实施组基线。
- **回传**：在 `workspace/02_changes/` 内建议的回传目录或回传记录中写入缺陷、变更与回归结论。
- **治理**：AI 活动在 `05_gov/workspace/` 登记。
