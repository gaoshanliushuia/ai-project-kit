# 01 测试与质量保证工作区

本目录用于保存测试阶段的测试策略、用例、数据、执行记录、缺陷复测和质量报告。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_inputs/`：需求验收条件、设计流程、接口契约、版本范围和已知风险。
- `02_strategy/`：测试策略、测试计划、范围、类型、优先级和退出标准。
- `03_cases/`：测试用例、需求追踪矩阵、接口测试和回归用例。
- `04_data-env/`：测试数据、环境信息、账号权限、配置和依赖记录。
- `05_execution/`：测试执行记录、结果截图、失败记录和复测记录。
- `06_reports/`：质量报告、发布建议、遗留风险和测试总结。

## 使用建议

- 高优先级需求应有对应测试用例和验收记录。
- 缺陷记录应包含复现步骤、实际结果、期望结果和影响范围。
- 质量报告应明确是否建议发布，以及阻塞原因或风险接受结论。
