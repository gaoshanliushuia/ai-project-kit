# playbook 目录说明（变更管理组）

`playbook` 是变更管理组的标准库，用于定义变更登记、影响分析、审批跟踪、实施同步和关闭复盘的执行标准。

## 本组阶段

```text
playbook/
└── 01_change/
```

## 阶段关系

```text
需求 / 实施 / 测试 / 发布 / 交付阶段
    -> 01_change
    -> workspace/ 统一登记变更记录
    -> 受影响阶段同步更新
```

AI 治理见 `06_gov/playbook/01_governance/`。

## 使用原则

- 每个变更必须关联 `CR` 编号和触发源。
- 变更记录至少说明触发来源、变更概述、影响范围、处理结论和引用链路。
- 需要其他阶段处理的内容必须明确责任人和回传方式。
- AI 留痕写入 `06_gov/workspace/`。
