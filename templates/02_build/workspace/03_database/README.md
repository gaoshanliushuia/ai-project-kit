# 03 数据库设计工作区

本目录用于保存数据库设计阶段的数据模型、字段字典、脚本、迁移方案和数据质量材料。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_inputs/`：数据需求、接口字段、报表需求、审计要求和历史数据资料。
- `02_models/`：概念模型、逻辑模型、物理模型、ER 图和模型说明。
- `03_dictionary/`：表结构、字段字典、索引、约束、字典值和审计字段。
- `04_scripts/`：DDL、DML、初始化数据、迁移脚本、回滚脚本。
- `05_quality/`：数据质量规则、校验清单、容量评估和性能说明。
- `06_reviews/`：数据库评审记录、问题关闭记录和变更说明。

## 使用建议

- 数据库变更应能关联到需求、设计或变更单。
- 迁移脚本应说明执行顺序、前置条件、回滚或补偿方式。
- 敏感字段应标注分类、访问控制和脱敏要求。
