# 02_build workspace

实施组各阶段产物与 `playbook/` 下同名阶段对应。

| 目录 | 职责 |
|------|------|
| `01_architecture/` | 架构设计、技术决策与架构追踪 |
| `02_design/` | 详细设计（common、modules、interfaces、database） |
| `03_code/` | 源码、构建、测试、评审、缺陷与运行材料 |
| `04_release/` | 版本发布、部署与迭代记录 |

引用需求时注明 `01_req/workspace/03_baseline/` 中的基线版本。
