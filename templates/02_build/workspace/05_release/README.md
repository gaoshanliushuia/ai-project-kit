# 05 版本发布与迭代工作区

本目录用于保存发布阶段的版本计划、发布清单、部署说明、回滚方案、验证记录和复盘材料。模板默认只创建到本目录；下级目录请按需创建。

## 建议子目录

- `01_scope/`：版本范围、包含需求、排除项、已知问题和风险接受记录。
- `02_artifacts/`：构建产物索引、配置项、脚本、部署包和发布材料。
- `03_deployment/`：部署说明、环境检查、权限检查、依赖检查和上线窗口。
- `04_rollback/`：回滚步骤、触发条件、补偿方案和演练记录。
- `05_verification/`：发布验证记录、异常处理、结果确认和通过范围。
- `06_retrospective/`：发布问题、用户反馈、改进项和下一轮迭代建议。

## 使用建议

- 每个发布项应能关联到需求、变更或缺陷。
- 发布前检查项、回滚步骤和验证结论应形成可执行记录。
- 交接给交付组时，应明确版本号、验收范围、账号权限和运维注意事项。
