# 04 代码实现与工程管理工作区

本目录用于保存代码阶段的源码、脚本、构建记录、测试记录、代码评审和工程管理材料。模板默认只创建到本目录；下级目录请按需创建。

开发实现计划文档统一放在 `02_build/workspace/02_design/implementation/`。本目录只保存代码和代码交付相关材料，不保存实现计划文件。

## 建议子目录

- `01_source/`：源码、脚本、配置和与可运行工程直接相关的文件。
- `02_builds/`：本地构建、流水线记录、构建产物索引和失败处理记录。
- `03_tests/`：单元测试、集成测试、静态检查、依赖检查和验证证据。
- `04_reviews/`：代码评审记录、问题清单、修复记录和复审结论。
- `05_defects/`：缺陷修复记录、技术债、临时方案和遗留风险。
- `06_runtime/`：配置说明、环境变量、运行说明、部署依赖和排障 notes。

## 使用建议

- 代码变更应能追踪到需求、设计项和模块级开发实现文档。
- 关键路径代码应有测试或人工验证证据。
- 临时方案必须记录失效条件和后续处理计划。
- 不要把 `implementation-plan` 或模块级实现文档复制到本目录。
