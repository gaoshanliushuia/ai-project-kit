# 详细设计 Skill

## 目标

把架构方案细化为开发可执行、测试可验证、变更可分析的设计产物。

## 适用角色

- `Architect Agent / Developer Agent`

## 输入

需求编号、验收条件、架构决策、模块边界、接口约束、数据和权限规则。

## 输出

模块设计、接口契约、流程图、状态机、异常处理、设计追踪矩阵。

## 执行步骤

- 明确模块职责、输入输出、依赖关系和边界条件。
- 设计接口字段、类型、校验、鉴权、错误码、超时、重试和幂等。
- 补齐主流程、异常流程、补偿流程和并发场景。
- 定义状态流转、禁止条件和终态。
- 提取开发任务和测试关注点。

## 使用要求

- 先读取本阶段 `rules/RULE.md`，再生成或检查阶段产物。
- 所有结论必须能追踪到输入材料、编号、负责人或评审记录。
- AI 生成内容只作为初稿或检查建议，关键结论必须由阶段负责人确认。
- 发现可复用经验时，回写本阶段 `rules/`、`skills/` 或 `prompts/`，并在后续版本发布中说明。
