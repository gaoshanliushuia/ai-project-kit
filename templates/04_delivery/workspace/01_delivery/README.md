# 01 项目交付与验收

## 本阶段目录用途

用于保存交付包、上线准备、验收、培训、用户手册、运维交接、遗留问题和交付复盘。这里的材料应能支撑客户签收、业务接手和后续运维。

## 建议目录

```text
01_go-live/           上线计划、上线检查、窗口安排和应急支持
02_acceptance/        验收标准、验收记录、签收材料和补充说明
03_training/          培训计划、培训材料、签到和反馈
04_manuals/           用户手册、操作说明、FAQ 和常见问题
05_operations/        运维交接、账号权限、监控、备份和联系人
06_open-items/        遗留问题、责任人、期限和验收影响判断
07_support/           上线后支持记录、问题响应和观察期记录
08_retrospective/     交付总结、项目复盘和改进建议
```

## 推荐文件

- `01_go-live/go-live-checklist.md`
- `02_acceptance/acceptance-record.md`
- `04_manuals/user-manual.md`
- `05_operations/operation-handoff.md`
- `06_open-items/open-item-register.md`
- `08_retrospective/delivery-retrospective.md`

## 阶段完成标志

- 验收项能关联到需求、合同或变更编号。
- 交付包清单完整，且能关联到发布版本。
- 影响验收的遗留问题已关闭或获得书面接受。
- 运维交接资料、账号权限和联系人完整。
- 上线观察期问题有分级、响应和处理记录。
