# playbook 目录说明（交付组）

`playbook` 是交付组的标准库，用于定义项目交付、验收签署、资料移交和运维交接的执行标准。

## 本组阶段

```text
playbook/
└── 01_delivery/
```

## 阶段关系

```text
02_build/05_release
    -> 04_delivery/01_delivery
    -> 05_gov/workspace/（AI 治理留痕）
```

## 使用原则

- 交付材料必须能关联到需求、合同、变更或发布版本。
- 源代码、构建产物、部署包、用户手册、验收记录和运维资料应形成可签收清单。
- 影响验收的问题必须明确关闭状态、责任人、期限或书面接受结论。
- AI 留痕写入 `05_gov/workspace/`。
